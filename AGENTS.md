# Instrucciones para el agente

Este proyecto sirve para crear imágenes de Instagram de productos destacados de Maquivo a partir del enlace del anuncio que facilite el usuario.

- Antes de crear una publicación, leer [productos-destacados/INSTRUCCIONES.md](productos-destacados/INSTRUCCIONES.md) e inspeccionar las imágenes de `productos-destacados/recursos/`.
- Si el usuario aporta un enlace de producto para crear un post, ejecutar el trabajo y entregar la imagen final. No devolver únicamente otro prompt.
- Consultar la ficha actual y usar la fotografía del propio producto. Conservar exactamente modelo, aspecto y características. No sustituirlo por un producto parecido.
- Mantener la plantilla, el logo y los colores corporativos salvo que el usuario pida cambiarlos.
- No inventar precios, IVA, descuentos, características, stock, envío, garantía ni financiación.
- Si falta información secundaria, omitirla. Si no se puede acceder a la ficha o a la foto, pedir solamente el material imprescindible que falte.
- Usar la herramienta integrada de imágenes cuando esté disponible. Si no hay capacidad de generar o editar imágenes, explicar la limitación y conservar el contenido preparado; no afirmar que se ha generado un archivo inexistente.
- Guardar cada trabajo en `productos-destacados/publicaciones/AAAA-MM-DD-nombre-producto/`. Conservar los recursos maestros intactos y no sobrescribir publicaciones existentes.
- Entregar en español y con enlaces a los archivos creados. Crear una publicación no autoriza a publicarla en Instagram ni a enviar mensajes a terceros.
