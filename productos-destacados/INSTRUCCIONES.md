# Crear un post de producto destacado para Maquivo

## Objetivo

A partir de un enlace público de producto de Maquivo, crear una imagen comercial para Instagram con una fotografía grande, nombre claro, precio destacado y hasta tres datos relevantes. Mantener un diseño coherente entre publicaciones.

El usuario solo tiene que proporcionar el enlace. Si la ficha es accesible y contiene lo necesario, no pedirle que copie manualmente sus datos ni que rellene un formulario.

## Recursos maestros

- Referencia visual: [recursos/plantilla-maquivo.png](recursos/plantilla-maquivo.png).
- Logo auténtico: [recursos/logo-maquivo.webp](recursos/logo-maquivo.webp).

Abrir ambos archivos antes de trabajar. Conservarlos intactos. La referencia contiene campos vacíos y un importe ficticio que deben sustituirse en todas las publicaciones.

## Diseño

| Elemento | Regla |
| --- | --- |
| Formato | Vertical 4:5; objetivo de exportación 1080 × 1350 px. Comprobar las dimensiones reales antes de anunciarlas. |
| Cabecera | Fondo blanco, logo auténtico y texto «MARKETPLACE INDUSTRIAL». |
| Cinta | Amarilla, con «PRODUCTO DESTACADO». |
| Fotografía | Foto principal del anuncio, con el producto completo y sin deformaciones. Debe ser el protagonista. |
| Panel inferior | Azul, con nombre del producto y bloque amarillo para el precio. |
| Nombre | Preferiblemente dos líneas como máximo. Mantener marca, modelo y referencias necesarias para identificarlo. |
| Subtítulo | Marca y modelo cuando aporten información y consten en la ficha. Evitar duplicar el nombre. |
| Características | Hasta tres datos verificados, con unidades. Ajustar las columnas si hay menos. |
| Proveedor | Nombre y ubicación cuando sean públicos en la ficha. |
| Cierre | «Descúbrelo en maquivo.com». |

Colores: azul principal `#002D62`, amarillo `#FFD100`, blanco `#FFFFFF` y gris muy claro de apoyo `#F3F5F8`. Conservar el azul propio del archivo del logo; no recolorearlo para igualarlo al panel.

Usar tipografía sans serif gruesa, título ligeramente inclinado y márgenes seguros. Mantener buena legibilidad en un móvil. No añadir adornos que compitan con el producto o el precio.

La plantilla adjunta mide 1122 × 1402 px y funciona como referencia de composición. No confundir esas dimensiones con la exportación final solicitada. Si la herramienta no permite exportar a 1080 × 1350 px, entregar la imagen con sus dimensiones reales e indicar la diferencia.

## Flujo de trabajo

### 1. Leer la ficha actual

Abrir el enlace del usuario con las herramientas web disponibles y leer la ficha completa. No basarse únicamente en fragmentos de un buscador ni en datos de publicaciones anteriores.

Registrar:

- URL del anuncio y fecha de consulta.
- Nombre completo, marca, modelo y referencia, si aparecen.
- Precio, moneda, unidad de venta y modalidad: fijo, desde o a consultar.
- Condición fiscal del precio si está indicada.
- Estado, disponibilidad y características técnicas relevantes.
- Proveedor y ubicación pública.
- URL y archivo de la fotografía seleccionada.

Si hay datos contradictorios que afecten al precio o a la identidad del producto, pedir aclaración antes de convertirlos en una afirmación comercial.

### 2. Obtener la foto del anuncio

Descargar e inspeccionar una fotografía de la propia ficha. Elegir una imagen nítida que muestre el producto completo. Si la primera no sirve, revisar las demás fotos del mismo anuncio.

Conservar la imagen original en la carpeta de esa publicación. No buscar una máquina parecida para sustituirla. No cambiar modelo, color, conexiones, número de piezas, etiquetas, accesorios incluidos, desgaste o defectos.

Se puede encuadrar o limpiar el fondo siempre que el producto permanezca fiel a la imagen original. No eliminar marcas de agua de terceros. No añadir accesorios que no se vendan con el producto.

Si la foto no se puede recuperar, pedir al usuario que la adjunte. No generar un producto ficticio para completar el anuncio.

### 3. Seleccionar los textos

Preparar los textos definitivos antes de componer la imagen.

| Campo | Tratamiento |
| --- | --- |
| Nombre | Abreviar sin alterar la identidad del producto. |
| Precio fijo | Copiar importe y moneda, conservando los decimales y la unidad. |
| Precio «desde» | Usar «desde» únicamente cuando lo indique la ficha. |
| Precio ausente o a consultar | Mostrar «A CONSULTAR». |
| IVA | Indicar «IVA incluido» o «+ IVA» solo si se especifica. |
| Condición del precio sin información | Omitir la línea o mostrar «Ver condiciones en la ficha». |
| Precio por unidad/lote | Conservar expresamente esa condición; no hacer conversiones no solicitadas. |
| Características | Usar hasta tres datos verificados y relevantes. |
| Proveedor o ubicación ausente | Mostrar solo lo disponible, sin separadores vacíos. |

Ejemplos de características según el producto: potencia/capacidad/presión para un compresor; tensión/capacidad/química para una batería; marca/referencia/estado para un recambio; medida/cantidad/material para un lote.

Estos ejemplos sirven para elegir datos, no para inventarlos cuando falten.

No añadir descuentos, precios tachados, financiación, envío gratis, garantías, certificaciones, urgencia o disponibilidad sin respaldo en la ficha o confirmación explícita del usuario.

Maquivo es el marketplace del anuncio. No presentarlo como fabricante, propietario del producto o vendedor responsable de las condiciones. No usar «enlace en la bio» salvo que el usuario confirme que ese enlace está configurado.

### 4. Crear la imagen

Usar la herramienta integrada de generación o edición de imágenes cuando esté disponible. Darle tres entradas con funciones explícitas:

1. La plantilla: referencia de composición, distribución, tipografía y colores.
2. El logo: identidad corporativa que debe respetarse fielmente.
3. La fotografía del anuncio: producto real que debe aparecer en la imagen.

Indicar el texto definitivo exacto y pedir que se cambien los campos variables manteniendo el diseño. Eliminar el icono de foto, sus esquinas y todos los textos de ejemplo del área central. No dejar «NOMBRE DEL PRODUCTO», «DATO 1», «0.000 €» u otros campos de la plantilla en el resultado.

Trabajar sobre una copia. No modificar los recursos maestros. Crear una imagen por enlace salvo que el usuario pida carrusel, story u otro formato.

Si la herramienta altera el producto, corregir esa desviación antes de entregar. Si no puede conservarlo con fidelidad, informar de esa limitación en lugar de presentar una representación engañosa como imagen definitiva.

### 5. Revisar y guardar

Comprobar visualmente:

- El producto coincide con el original y conserva sus detalles.
- El logo está bien escrito y mantiene su forma y su I amarilla.
- El nombre, precio, moneda, decimales y unidades coinciden con la ficha.
- Las condiciones del precio no se han supuesto.
- Los textos se leen, no están cortados y no se solapan.
- No quedan campos de ejemplo ni afirmaciones sin respaldo.
- El archivo existe, se abre y sus dimensiones se conocen.

Guardar en `publicaciones/AAAA-MM-DD-nombre-producto/`:

| Archivo | Contenido |
| --- | --- |
| `post.png` | Imagen final de la publicación. |
| `foto-original.ext` | Fotografía del anuncio sin modificar, con su extensión real. |
| `datos.md` | URL, fecha de consulta, datos utilizados, textos definitivos y cualquier información pendiente. |

Si ya existe esa carpeta, añadir un sufijo `-v2`, `-v3`, etc. No sobrescribir versiones anteriores.

Entregar la imagen con un mensaje breve en español. Si el usuario también pide el texto para Instagram, redactarlo usando los mismos datos verificados y guardarlo como `caption.md`. No crear pies de publicación largos o adicionales sin necesidad.
